AKSPBS / KLSWA

Member Login

Existing registered members can activate login access, sign in, check their own record, and submit correction requests when needed.

Activate existing member

Use the phone number and LS number already saved in KLSWA data. Date of birth is checked when available in the record.

Member sign in

Login using phone number, LS number, or Mojini login ID after activation.

Forgot password

Reset password using the same identity details used for activation.
